# @kayushkin/multichat-types

TypeScript types for multichat's inbound rules, message log and Discord bridge status, rendered by `../generate-ts.sh`: `db.ts` from `internal/db/inbound.go` and `internal/db/message_log.go`, `discord_status.ts` from `internal/discordbridge/status.go`. `index.ts` re-exports both. Do not edit the rendered files by hand.
